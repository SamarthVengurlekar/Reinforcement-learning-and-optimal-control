Mock exam built from your practicals

A second full paper in the same shape as 2024 (3 questions, 100 marks): MPC in words, stochastic DP by hand, then a learning algorithm by hand. Every question is a variation on something you did in P1–P6. Sit it in exam time with only the cheatsheet, then open the solutions.

Format

Q1 MPC (25) · Q2 Stochastic DP (40) · Q3 Q-learning vs SARSA (35). Show the recursion or update for every step; most marks are for the working, not the final number.

Question 1 · Model Predictive Control (25 marks)

A gantry crane cart moves along a 12 m track and carries a load modelled as a rigid rod. The state is \(x=[p,\ v,\ \theta,\ \omega]^\top\) and the input is the motor force u. The cart starts at rest at p = 2 m and must stop with no swing at p = 10 m within 10 s. The cart is rated to 3 m/s, the motor gives at most 100 N, and for safety the load must not swing more than 10° or faster than 50°/s. The controller samples at Ts = 0.1 s.

1(a)6 marks

Write down the initial condition, the target state, and all state and input constraints, in SI units.

Show solution

\(x_0=[2,0,0,0]^\top\), \(x^*=[10,0,0,0]^\top\). Constraints: \(0\le p\le12\) m; \(-3\le v\le3\) m/s; \(|\theta|\le10^\circ=0.1745\) rad; \(|\omega|\le50^\circ/\text{s}=0.8727\) rad/s; \(-100\le u\le100\) N. Note that the angle limit also keeps the system where the linearised model is valid.

1(b)6 marks

Propose Q and R using Bryson's rule. State the rule and explain what it achieves.

Show solution

Rule: \(Q_{ii}=1/(x_i^{\max})^2\), \(R=1/(u^{\max})^2\). It scales each term so that a state at its largest acceptable value costs about 1, which normalises different units (metres vs radians). Q = diag(1/8², 1/3², 1/0.1745², 1/0.8727²) ≈ diag(0.016, 0.11, 32.8, 1.31); R = 1/100² = 10−4. It is a starting point; you then tune by simulation (raising the θ, ω weights if the swing is the binding constraint, or the p weight if it is too slow).

1(c)7 marks

An LQR design meets every limit but settles in 7.3 s and only reaches 1.8 m/s. Explain why LQR is conservative here and how constrained MPC with the receding-horizon principle improves on it.

Show solution

LQR is a fixed linear law \(u=-K(x-x^*)\); its largest push is at t = 0 when the error is largest (8 m). To keep the swing within limits at that worst moment the gains must be small, which slows the whole move. Constraints are met only indirectly through tuning, and the swing scales with the move size, so a longer move would break the limits.

MPC writes the limits directly as inequalities on the predicted states and inputs over the horizon N and solves a QP each sample. It applies only the first input, then re-measures and re-solves (receding horizon), giving feedback \(u_k=\kappa(x_k)\). The controller can then run on the limits when that helps (v near 3 m/s, θ at 10°) and back off when needed. In the practical: 5.4 s with no overshoot vs 7.3 s for LQR. Simple weights (Q = I, R = 1) suffice because the constraints, not the weights, enforce safety.

1(d)6 marks

For a 3 s horizon, how many decision variables and inequality constraints does the condensed QP have? Discuss the computational implications of the horizon choice.

Show solution

N = 3/0.1 = 30. Decision variables: 30 (one scalar input per step). Inequalities: 2·4·30 = 240 state bounds + 2·30 = 60 input bounds = 300. The Hessian \(H=2(\Phi^\top\bar Q\Phi+\bar R)\) is 30×30 and constant, but the QP must be solved every sample and finish within 100 ms. Solve time grows roughly as N² to N³. Too short an N (0.5–1 s) is cheap but short-sighted, settles slowly and can become infeasible (no terminal constraint means no recursive-feasibility guarantee). Beyond about 3 s there was no performance gain, only extra computation.

2(a)(ii)10 marks

Keeping ρ = 0.5 and S = 3, find the range of search cost c for which the driver should park at k = 0 when it is free. Interpret the result.

Show solution

Work symbolically. k = 2: drive = c + 3, so J2(free) = min(1, c+3) = 1 and J2(full) = c + 3. k = 1: drive = c + 0.5(1) + 0.5(c+3) = 1.5c + 2, so J1(free) = min(2, 1.5c+2) = 2 and J1(full) = 1.5c + 2. k = 0: drive = c + 0.5(2) + 0.5(1.5c+2) = 1.75c + 2.

Park at k = 0 iff 3 ≤ 1.75c + 2 ⇔ c ≥ 4/7 ≈ 0.571. Check: c = 0.4 gives 2.7 < 3 (drive), as in (i). Interpretation: the fee falls by 1 per park, so skipping a park is worth it only while the expected search cost is low enough. Expensive searching makes the driver take the first free spot (like your P3 baseline with c = 1).

(b) Random road closure. From A, Tom chooses East (reaches B with probability 0.6, otherwise C) or West (reaches D with probability p, otherwise E), learning which only at the fork. Leg costs: A→B 333, A→C 282, A→D 230, A→E 300; B→F 553, B→G 280; C→F 470, C→G 404; D→F 268, D→G 606; E→F 807, E→G 370; F→H 450, G→H 603.

2(b)15 marks

(i) Compute J(B), J(C), J(D), J(E) and the expected cost of East. (ii) For p = 0.5, should Tom go East or West? (iii) Find the value of p below which East is optimal.

Show solution

(i) J(F) = 450, J(G) = 603. J(B) = min(553+450, 280+603) = 883 (G); J(C) = min(470+450, 404+603) = 920 (F); J(D) = min(268+450, 606+603) = 718 (F); J(E) = min(807+450, 370+603) = 973 (G). East = 0.6(333+883) + 0.4(282+920) = 729.6 + 480.8 = 1210.4.

(ii) West = 0.5(230+718) + 0.5(300+973) = 474 + 636.5 = 1110.5 < 1210.4, so go West.

(iii) West = 948p + 1273(1−p) = 1273 − 325p. East is better when 1273 − 325p > 1210.4 ⇔ p < 0.193.

The decision at A is made before the closure is revealed, so it uses the expectation. Decisions at B to E are made after, so they are deterministic minimisations. The answer is a policy: West; then D→F→H if at D, or E→G→H if at E.

Question 3 · Q-learning vs SARSA (35 marks)

A small cliff problem. States 1 (start), 2 (cliff edge), 3 and 4 (safe route), G (goal, terminal, Q(G,·) = 0). Moves: 1–A→2, 1–B→3, 2–A→G, 2–B→1 (falls off, reward −100), 3–A→4, 3–B→1, 4–A→G, 4–B→3. Every move other than the fall gives reward −1. Use learning rate δ = 0.5, discount α = 0.9, Q-table initialised to 0, and the pre-sampled ε-greedy episodes

ep1 = 1 –A→ 2 –B→ 1 –B→ 3 –A→ 4 –A→ G    ep2 = 1 –A→ 2 –B→ 1 –A→ 2 –A→ G

3(b)7 marks

Give the greedy route from 1 for each table. Do they agree? Is that the end of the story?

Show solution

Rewards, so take the argmax. SARSA: Q(1,B) = −0.5 > −12.125, so B, then 3–A, 4–A: 1→3→4→G (the safe route). Q-learning: Q(1,B) = −0.5 > −0.875, so also B: 1→3→4→G.

They agree for now, but for different reasons. Q-learning's preference is only an artefact of too little data: the safe route's values have been updated as if it took one step (−0.5) because the −1s haven't propagated back yet. SARSA's preference is structural: it has learned that, while exploring, stepping onto the edge is dangerous. With more episodes, Q-learning will switch to the edge (see (c)).

3(c)8 marks

Compute the true optimal Q*(1,A) and Q*(1,B) from the Bellman equation. Which route does each algorithm converge to with (i) a constant ε = 0.2, (ii) εk → 0? Explain.

Show solution

Q*(2,A) = −1, Q*(4,A) = −1, Q*(3,A) = −1 + 0.9(−1) = −1.9. Q*(1,A) = −1 + 0.9·max(Q*(2,A), Q*(2,B)) = −1 + 0.9(−1) = −1.9. Q*(1,B) = −1 + 0.9·Q*(3,A) = −1 + 0.9(−1.9) = −2.71. The optimal route is the edge 1→2→G.

(i) Constant ε = 0.2: Q-learning is off-policy, so it still converges to Q* and the greedy route is the edge. SARSA converges to the Q-factors of the ε-greedy policy: at state 2 it picks B (the fall) with probability ε/2 = 0.1. Roughly, stepping onto the edge is then worth about 0.9(−1) + 0.1(−100 − …) ≈ −11 or worse, much worse than the safe route (≈ −2.7), so SARSA keeps the safe route.

(ii) With εk → 0 (greedy in the limit) and Robbins–Monro step sizes, SARSA's target becomes Q-learning's, and both converge to Q* and the edge route. This matches P6: SARSA with ε = 0 learned the 13-step edge path on every seed.
