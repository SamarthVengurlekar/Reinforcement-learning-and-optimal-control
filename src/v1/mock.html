Question 1 · Model Predictive Control (25 marks)

A gantry crane cart moves along a 12 m track and carries a load modelled as a rigid rod. The state is \(x=[p,\ v,\ \theta,\ \omega]^\top\) and the input is the motor force u. The cart starts at rest at p = 2 m and must stop with no swing at p = 10 m within 10 s. The cart is rated to 3 m/s, the motor gives at most 100 N, and for safety the load must not swing more than 10° or faster than 50°/s. The controller samples at Ts = 0.1 s.

1(a)6 marks

Write down the initial condition, the target state, and all state and input constraints, in SI units.

Show solution

\(x_0=[2,0,0,0]^\top\), \(x^*=[10,0,0,0]^\top\). Constraints: \(0\le p\le12\) m; \(-3\le v\le3\) m/s; \(|\theta|\le10^\circ=0.1745\) rad; \(|\omega|\le50^\circ/\text{s}=0.8727\) rad/s; \(-100\le u\le100\) N. Note that the angle limit also keeps the system where the linearised model is valid.

1(b)6 marks

Propose Q and R using Bryson's rule. State the rule and explain what it achieves.

Show solution

Rule: \(Q_{ii}=1/(x_i^{\max})^2\), \(R=1/(u^{\max})^2\). It scales each term so that a state at its largest acceptable value costs about 1, which normalises different units (metres vs radians). Q = diag(1/8², 1/3², 1/0.1745², 1/0.8727²) ≈ diag(0.016, 0.11, 32.8, 1.31); R = 1/100² = 10−4. It is a starting point; you then tune by simulation (raising the θ, ω weights if the swing is the binding constraint, or the p weight if it is too slow).

1(c)7 marks

An LQR design meets every limit but settles in 7.3 s and only reaches 1.8 m/s. Explain why LQR is conservative here and how constrained MPC with the receding-horizon principle improves on it.

Show solution

LQR is a fixed linear law \(u=-K(x-x^*)\); its largest push is at t = 0 when the error is largest (8 m). To keep the swing within limits at that worst moment the gains must be small, which slows the whole move. Constraints are met only indirectly through tuning, and the swing scales with the move size, so a longer move would break the limits.

MPC writes the limits directly as inequalities on the predicted states and inputs over the horizon N and solves a QP each sample. It applies only the first input, then re-measures and re-solves (receding horizon), giving feedback \(u_k=\kappa(x_k)\). The controller can then run on the limits when that helps (v near 3 m/s, θ at 10°) and back off when needed. In the practical: 5.4 s with no overshoot vs 7.3 s for LQR. Simple weights (Q = I, R = 1) suffice because the constraints, not the weights, enforce safety.

1(d)6 marks

For a 3 s horizon, how many decision variables and inequality constraints does the condensed QP have? Discuss the computational implications of the horizon choice.

Show solution

N = 3/0.1 = 30. Decision variables: 30 (one scalar input per step). Inequalities: 2·4·30 = 240 state bounds + 2·30 = 60 input bounds = 300. The Hessian \(H=2(\Phi^\top\bar Q\Phi+\bar R)\) is 30×30 and constant, but the QP must be solved every sample and finish within 100 ms. Solve time grows roughly as N² to N³. Too short an N (0.5–1 s) is cheap but short-sighted, settles slowly and can become infeasible (no terminal constraint means no recursive-feasibility guarantee). Beyond about 3 s there was no performance gain, only extra computation.

Question 3 · Q-learning vs SARSA (35 marks)

A small cliff problem. States 1 (start), 2 (cliff edge), 3 and 4 (safe route), G (goal, terminal, Q(G,·) = 0). Moves: 1–A→2, 1–B→3, 2–A→G, 2–B→1 (falls off, reward −100), 3–A→4, 3–B→1, 4–A→G, 4–B→3. Every move other than the fall gives reward −1. Use learning rate δ = 0.5, discount α = 0.9, Q-table initialised to 0, and the pre-sampled ε-greedy episodes

ep1 = 1 –A→ 2 –B→ 1 –B→ 3 –A→ 4 –A→ G    ep2 = 1 –A→ 2 –B→ 1 –A→ 2 –A→ G

3(a)20 marks

Process ep1 then ep2 with (i) SARSA and (ii) Q-learning. Show every update and give both final Q-tables.

Show solution
SARSA · on-policy

Target = r + 0.9·Q(x′, u′), where u′ is the action the episode actually takes next. To find u′, look one arrow further along the episode string.

Each update uses (x, u, r, x′, u′), which is where the name S-A-R-S-A comes from.

Q-learning · off-policy

Target = r + 0.9·maxu Q(x′, u). Look at every action at x′ in the current table and take the best one (max for rewards, min for costs). The action actually taken next is ignored.

Each update uses only (x, u, r, x′).

The rest is the same for both methods. Both use the update Q(x,u) ← Q(x,u) + 0.5·(target − Q(x,u)). Both use target = r when x′ = G, because Q(G,·) = 0. Both always read the current table, including changes made earlier in the same episode. So the only thing that differs is which Q(x′,·) value goes into the target.

Why they differ. At step 6 the agent stands at the cliff edge, and the episode shows it then fell (an exploratory move). SARSA learns from that real next move, so Q(1,A) means "going to the edge is bad, because I sometimes fall off". Q-learning bootstraps from the best move at the edge, (2,A), so Q(1,A) means "going to the edge is fine, provided I act optimally afterwards". The −50 is still in the table for Q-learning, but the max never picks it.

Exam traps

1. Using the max in SARSA, or the next action in Q-learning. Write "SARSA uses u′ =" or "max over x′ =" before every target.

2. Using a stale value. Step 7 must use the Q(1,A) just updated at step 6. Update the table in place, in episode order.

3. Max or min. These are rewards, so take the max. If the question gives costs, take the min.

4. The terminal step. There is no bootstrap term (target = r), in both methods.

3(b)7 marks

Give the greedy route from 1 for each table. Do they agree? Is that the end of the story?

Show solution

Rewards, so take the argmax. SARSA: Q(1,B) = −0.5 > −12.125, so B, then 3–A, 4–A: 1→3→4→G (the safe route). Q-learning: Q(1,B) = −0.5 > −0.875, so also B: 1→3→4→G.

They agree for now, but for different reasons. Q-learning's preference is only an artefact of too little data: the safe route's values have been updated as if it took one step (−0.5) because the −1s haven't propagated back yet. SARSA's preference is structural: it has learned that, while exploring, stepping onto the edge is dangerous. With more episodes, Q-learning will switch to the edge (see (c)).

3(c)8 marks

Compute the true optimal Q*(1,A) and Q*(1,B) from the Bellman equation. Which route does each algorithm converge to with (i) a constant ε = 0.2, (ii) εk → 0? Explain.

Show solution

Q*(2,A) = −1, Q*(4,A) = −1, Q*(3,A) = −1 + 0.9(−1) = −1.9. Q*(1,A) = −1 + 0.9·max(Q*(2,A), Q*(2,B)) = −1 + 0.9(−1) = −1.9. Q*(1,B) = −1 + 0.9·Q*(3,A) = −1 + 0.9(−1.9) = −2.71. The optimal route is the edge 1→2→G.

(i) Constant ε = 0.2: Q-learning is off-policy, so it still converges to Q* and the greedy route is the edge. SARSA converges to the Q-factors of the ε-greedy policy: at state 2 it picks B (the fall) with probability ε/2 = 0.1. Roughly, stepping onto the edge is then worth about 0.9(−1) + 0.1(−100 − …) ≈ −11 or worse, much worse than the safe route (≈ −2.7), so SARSA keeps the safe route.

(ii) With εk → 0 (greedy in the limit) and Robbins–Monro step sizes, SARSA's target becomes Q-learning's, and both converge to Q* and the edge route. This matches P6: SARSA with ε = 0 learned the 13-step edge path on every seed.

Question 1 · Batch MPC by hand (25 marks)

Consider the scalar system \(x_{k+1}=0.9x_k+0.5u_k\) with MPC cost \(J=\sum_{l=0}^{N-1}\big(Q x_{k+l|k}^2+R u_{k+l|k}^2\big)+Q_F x_{k+N|k}^2\), horizon N = 2, Q = 1, QF = 2, R = 0.1, and current state xk = 2.

1(a)8 marks

Write the predictions in batch form \(X=\Lambda x_k+\Phi U\) with \(X=[x_{k+1|k},x_{k+2|k}]^\top\), \(U=[u_{k|k},u_{k+1|k}]^\top\). Give Λ, Φ, and the QP Hessian H and linear term f for the form \(\tfrac12U^\top HU+f^\top U\).

Show solution

\(x_{k+1|k}=0.9x_k+0.5u_k\), \(x_{k+2|k}=0.81x_k+0.45u_k+0.5u_{k+1}\). So

\[\Lambda=\begin{bmatrix}0.9\\0.81\end{bmatrix},\quad \Phi=\begin{bmatrix}0.5&0\\0.45&0.5\end{bmatrix},\quad \bar Q=\mathrm{diag}(Q,Q_F)=\mathrm{diag}(1,2),\quad \bar R=0.1I.\]

\[H=2(\Phi^\top\bar Q\Phi+\bar R)=\begin{bmatrix}1.51&0.9\\0.9&1.2\end{bmatrix},\qquad f=2\Phi^\top\bar Q\Lambda x_k=\begin{bmatrix}4.716\\3.24\end{bmatrix}.\]

Find the unconstrained optimal U*. Which input is applied, and what happens at the next sample?

\(U^*=-H^{-1}f\). det H = 1.51·1.2 − 0.81 = 1.002, so \(H^{-1}=\frac1{1.002}\begin{bmatrix}1.2&-0.9\\-0.9&1.51\end{bmatrix}\) and

\[U^*=-\frac{1}{1.002}\begin{bmatrix}1.2(4.716)-0.9(3.24)\\-0.9(4.716)+1.51(3.24)\end{bmatrix}=\begin{bmatrix}-2.738\\-0.647\end{bmatrix}.\]

Predicted states: xk+1|k = 1.8 − 1.369 = 0.431, xk+2|k = 0.065. Only the first input uk = −2.738 is applied. At k+1 the real state is measured (it differs from 0.431 if there is noise or model error), and the whole QP is solved again from that state. This is the receding-horizon principle. With no constraints this gives a linear law, uk = −1.369xk.

\(G=\begin{bmatrix}I\\-I\end{bmatrix}\), \(h=[1,1,1,1]^\top\), i.e. \(u_{k|k}\le1,\ u_{k+1|k}\le1,\ -u_{k|k}\le1,\ -u_{k+1|k}\le1\).

Question 2 · Stochastic LQ dynamic programming (40 marks)

Consider \(x_{k+1}=x_k+u_k+w_k\) with \(E\{w_k\}=0\), \(E\{w_k^2\}=\sigma^2\), wk independent of xk, uk and of each other. Horizon N = 2, stage cost \(g_k=x_k^2+r\,u_k^2\) (r > 0), terminal cost \(g_2(x_2)=x_2^2\), and \(J_k(x_k)=\min_{u_k}E_{w_k}\{g_k+J_{k+1}(x_{k+1})\}\).

2(a)20 marks

Run the DP algorithm. Find J1(x), μ1(x), μ0(x) and J0(x) in general. Then evaluate them for r = 1.

Show solution

Key identity: \(E\{(a+w)^2\}=a^2+2aE\{w\}+E\{w^2\}=a^2+\sigma^2\).

k = 1: \(J_1(x)=\min_u\{x^2+ru^2+E[(x+u+w)^2]\}=x^2+\sigma^2+\min_u\{ru^2+(x+u)^2\}\). Setting the derivative to zero, \(2ru+2(x+u)=0\Rightarrow \mu_1(x)=-\frac{x}{1+r}\). Substituting, \(ru^2+(x+u)^2=\frac{r x^2}{1+r}\), so

\[J_1(x)=\frac{1+2r}{1+r}x^2+\sigma^2\equiv a_1x^2+\sigma^2.\]

k = 0: \(J_0(x)=\min_u\{x^2+ru^2+a_1[(x+u)^2+\sigma^2]+\sigma^2\}\). Differentiating, \(2ru+2a_1(x+u)=0\Rightarrow\mu_0(x)=-\frac{a_1}{r+a_1}x=-\frac{1+2r}{r^2+3r+1}x\), and

\[J_0(x)=\Big(1+\frac{r a_1}{r+a_1}\Big)x^2+(1+a_1)\sigma^2.\]

r = 1: a1 = 3/2, μ1(x) = −x/2, μ0(x) = −(3/5)x, J1(x) = 1.5x² + σ², and J0(x) = 1.6x² + 2.5σ².

2(b)10 marks

With r = 1 and x0 = 1, find σ² such that J0(x0) = 2.6.

Show solution

1.6(1)² + 2.5σ² = 2.6 ⇒ 2.5σ² = 1 ⇒ σ² = 0.4 (σ ≈ 0.632). Check: 1.6 + 2.5(0.4) = 2.6 ✓.

2(c)10 marks

The policies μk do not depend on σ. Explain why, what σ does change, and what happens to μ0 as r → 0 and r → ∞.

Show solution

The noise is additive with zero mean, so it adds the constant a·σ² to the expected cost whatever u is. A constant does not move the minimiser, so the optimal action equals the one for w = 0. This is certainty equivalence, which is exact for linear dynamics with quadratic cost. σ only raises the optimal cost, by (1 + a1)σ².

As r → 0 (cheap control), μ0 → −x: drive the state straight to 0 in one step. As r → ∞ (expensive control), μ0 → 0: do nothing and accept the state cost. R trades effort against regulation, as in MPC and LQR.

Question 1 · MPC concepts (25 marks)

1(a)8 marks

MPC solves an open-loop optimal control problem at every sample, yet the result is a closed-loop (feedback) controller. Explain, using the notation \(x_{k+l|k}\).

Show solution

\(x_{k+l|k}\) is the prediction of the state at time k+l made with the information available at time k. Each optimisation is open-loop: it plans the whole sequence \(u_{k|k},\dots,u_{k+N-1|k}\) from the measured xk and assumes the model is exact. Only \(u_{k|k}\) is applied. At k+1 the true xk+1 is measured and the problem is solved again. Because the applied input always depends on the latest measurement, MPC implements an implicit feedback law \(u_k=\kappa_N(x_k)\), which corrects for disturbances and model error. Example: in P1 the crane re-planned from the measured position and swing every 0.1 s, so an unexpected disturbance to the load would be corrected at the next sample.

1(b)9 marks

What can go wrong with a short horizon and no terminal ingredients? State the standard terminal cost and terminal set conditions that guarantee stability and recursive feasibility.

Show solution

With a short N the controller is myopic. The finite-horizon optimum can steer towards states from which the constraints cannot be satisfied later (loss of feasibility), and the closed loop can even be unstable, because the cost JN need not decrease from step to step.

Standard fix: (1) a terminal set \(\mathbb X_f\) that is control-invariant under a local controller \(\kappa_f\) (often the LQR, u = −Kx) with constraints satisfied inside it; (2) a terminal cost \(V_f=x^\top Q_Fx\) that is a local Lyapunov function, \(V_f(f(x,\kappa_f(x)))-V_f(x)\le-\ell(x,\kappa_f(x))\), e.g. QF = the Riccati solution P; (3) the constraint \(x_{k+N|k}\in\mathbb X_f\). Then the optimal cost J*N is a Lyapunov function, so the closed loop is asymptotically stable, and feasibility at k implies feasibility at k+1: shift the old plan and append \(\kappa_f\).

1(c)8 marks

When does MPC give exactly the same input as LQR? Why do engineers still use MPC?

Show solution

For a linear model with quadratic cost and QF = P (the solution of the discrete algebraic Riccati equation), the unconstrained MPC law is \(u=-Kx\) with the LQR gain, for any N. With constraints, the same holds whenever no constraint is active over the horizon (near the origin). MPC is still used because it (i) handles input, state and output constraints explicitly, so it can run on the limits (crane: 5.4 s vs 7.3 s), (ii) uses previews of references and disturbances, and (iii) works with nonlinear models and economic costs. The price is solving a QP online every sample.

Question 2 · Stochastic DP with packet dropouts (40 marks)

A controller sends uk over a wireless link. The packet arrives (γk = 1) with probability Γ, or is lost (γk = 0) with probability 1 − Γ, in which case the actuator applies 0. The system is \(x_{k+1}=x_k+\gamma_ku_k+w_k\) with wk zero-mean, variance σ², independent of γk. One stage remains: \(J_0(x)=\min_u E\{x^2+u^2+J_1(x_1)\}\) with \(J_1(x)=x^2\).

2(a)18 marks

Compute the expectation, then find μ0(x) and J0(x) as functions of Γ and σ².

Show solution

Condition on γ: \(E\{(x+\gamma u+w)^2\}=\Gamma(x+u)^2+(1-\Gamma)x^2+\sigma^2\). (Use γ² = γ and E{γ} = Γ, and the cross terms with w vanish.)

So \(J_0(x)=\min_u\{x^2+u^2+\Gamma(x+u)^2+(1-\Gamma)x^2\}+\sigma^2\). Setting the derivative to zero: \(2u+2\Gamma(x+u)=0\Rightarrow\)

\[\mu_0(x)=-\frac{\Gamma}{1+\Gamma}x,\qquad J_0(x)=\frac{2+2\Gamma-\Gamma^2}{1+\Gamma}\,x^2+\sigma^2.\]

(The minimum of \(u^2+\Gamma(x+u)^2\) is \(\frac{\Gamma}{1+\Gamma}x^2\); add \(x^2+(1-\Gamma)x^2\).)

2(c)10 marks

Show that the x² coefficient of J0 decreases as Γ increases. Explain in words why the controller is more cautious when packets may drop.

Show solution

\(\frac{d}{d\Gamma}\frac{2+2\Gamma-\Gamma^2}{1+\Gamma}=\frac{(2-2\Gamma)(1+\Gamma)-(2+2\Gamma-\Gamma^2)}{(1+\Gamma)^2}=\frac{-\Gamma^2-2\Gamma}{(1+\Gamma)^2}<0\) for Γ > 0. A more reliable link always lowers the cost.

The gain Γ/(1+Γ) shrinks as Γ falls. The input cost u² is paid whether or not the packet arrives, but the benefit (moving x towards 0) arrives only with probability Γ. So the expected return on control effort falls and the optimal controller uses less of it. Unlike additive noise, multiplicative uncertainty does change the policy, so certainty equivalence fails here.

3(c)7 marks

Without the model, you estimate J under some policy by TD(0) with step size 0.1. Your current estimates are J(1) = 6, J(2) = 8, and you observe a transition 1 → 2 with cost 0.5. Perform the update and explain the TD error.

Show solution

TD error \(d=g+\alpha J(x')-J(x)=0.5+0.9(8)-6=1.7\). Update \(J(1)\leftarrow J(1)+0.1d=6+0.17=\mathbf{6.17}\).

d > 0 means the observed one-step cost plus the discounted estimate of the next state is higher than J(1) predicted, so J(1) is moved up. TD(0) is the sampled, model-free version of the policy-evaluation step in PI. It replaces \(\sum_jp_{ij}J(j)\) with a single observed next state, and averages over many samples with a decreasing step size (Robbins–Monro).
