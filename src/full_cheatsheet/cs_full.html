1 · Model Predictive Control

1.1 Setup

  • Model xk+1 = f(xk,uk), f(0,0) = 0, constraints x ∈ 𝕏, u ∈ 𝕌.
  • xk+ℓ|k = state at k+ℓ predicted at time k (xk|k = measured xk); U = [uk|k; …; uk+N−1|k] (stacked future inputs).

J(xk,U) = Σℓ=0N−1 (xTQx + uTRu)k+ℓ|k + xTk+N|k QF xk+N|k

  • General form ΣL(x,u) + F(xk+N|k); design knobs L, F, N.

1.2 What Q, R, QF do

  • Q ≥ 0 (state weight): penalises distance from target. Bigger ⇒ drives x → 0 faster. Diagonal entries pick which states matter (diag(1,0) = position only).
  • R > 0 (input weight): penalises effort, fuel, actuator wear. Bigger ⇒ smaller, gentler inputs, slower response. R ≻ 0 ⇒ unique minimiser.
  • QF ≥ 0 (terminal weight): penalises where the plan ends; stands in for all cost after the horizon. Chosen from Lyapunov/Riccati ⇒ closed-loop stability.
  • Only the ratio matters (R = ρI): small ρ ⇒ fast convergence, large inputs; large ρ ⇒ slow, small inputs (input energy Jin vs output energy Jout trade-off; double integrator ρ = 0.3 vs 10).
  • Unstable plant with N = 1 and large ρ can be unstable in closed loop; a longer N or good QF fixes it.

1.3 Receding horizon optimisation

  • (1) Measure xk. (2) Solve U* = argminU∈𝕌N J(xk,U). (3) Apply only the first input uk = u*k|k = [I 0 … 0]U*. (4) k+1: measure, shift window, solve again.
  • Result is a feedback law uk = κ(xk); in general u*k+1|k ≠ u*k+1|k+1.
  • Why: corrects disturbances and model error, handles constraints, looks ahead, finite computation.
  • Longer N: better (long-term impact) but more computation; moderate N ≈ infinite horizon. Nonlinear models need numerical optimisation. Integral action: penalise uk+ℓ+1|k − uk+ℓ|k. State + input constraints may make it infeasible.

Example: xk+1 = x+u, N=2, Q=R=QF=1, x0=10. Plan rule uk|k = −0.6xk, uk+1|k = −0.5xk+1|k. k=0: plan −6 (x1|0=4), −2 (x2|0=2); apply −6 only. Wind ⇒ x1=5 ⇒ re-plan u=−3. Even if x1=4: u1|1 = −2.4 ≠ u1|0 = −2.

1.4 LTI, quadratic cost: explicit solution

  • xk+ℓ|k = Aℓxk + Σj=0ℓ−1Aℓ−j−1Buk+j|k ⇒ X = ΦU + Λxk (X = stacked predictions xk+1|k … xk+N|k).
  • Φ = [B 0 … 0; AB B … 0; … ; AN−1B … AB B], Λ = [A; A²; …; AN], Qblk = diag(Q,…,Q,QF), R = ρI.

J = xkT(ΛTQblkΛ+Q)xk + UT(ΦTQblkΦ+ρI)U + 2UTΦTQblkΛxk

U* = −(ΦTQblkΦ + ρI)−1ΦTQblkΛ xk

uk = −Kxk, K = first row block of (ΦTQblkΦ+ρI)−1ΦTQblkΛ

  • Uses ∂(uTXu)/∂u = 2Xu, ∂(aTu)/∂u = a. Constant gain = finite-horizon LQR; Hessian ≻ 0 (ρ > 0) ⇒ unique minimum.

Example: a=2, b=1, N=2, Q=QF=ρ=1: Φ = [1 0; 2 1], Λ = [2; 4], H = ΦTΦ+I = [6 2; 2 2], ΦTΛ = [10; 4], H−1 = ⅛[2 −2; −2 6] ⇒ U* = −[1.5; 0.5]xk; apply −1.5x ⇒ xk+1 = 0.5xk (stable).

  • Constraints ⇒ QP: min UTHU + UTf s.t. AinU ≤ bin, AeqU = beq; state limits become input limits via X = ΦU + Λxk (Kronecker 1N⊗[1 0 0] picks positions).
  • Discretise: double integrator A = [1 Δt; 0 1], B = [Δt²/2; Δt]; ZOH [A B; 0 I] = exp([Ac Bc; 0 0]Ts).

1.5 Stability

  • A1: F(0)=0, F ≥ 0, L(0,0)=0, L(x,u) ≥ α(‖x‖) (α increasing, α(0)=0). A2: local κf with F(f(x,κf(x))) ≤ F(x) − L(x,κf(x)) (terminal cost = Lyapunov function).
  • Proof: Vk = optimal cost. Shifted old plan + κf at the end is feasible with cost ≤ Vk − L ⇒ 0 ≤ Vk+1 ≤ Vk − α(‖xk‖) ⇒ V converges ⇒ xk → 0.
  • Finite input set: R = 0, κf = 0, QF from ATQFA + Q = QF (A stable; scalar QF = q/(1−a²)).

1.6 Vehicle platooning

  • Car: ṗ = v, v̇ = a, ȧ = −a/τ + u/τ (τ ≈ 1.5). Gap error ei,k = xi−1,k − xi,k, ek+1 = Aek + Būk, ui = ui−1 − ūi.
  • LQR (DARE) ignores limits ⇒ car 3 hits car 2, 288 km/h. MPC adds pmin = 3 m, 0 ≤ v ≤ 25 m/s, −6 ≤ a ≤ 3 m/s² ⇒ QP keeps gaps and limits.

2 · Deterministic DP

2.1 Principle of optimality

  • "The rest of an optimal trajectory, from any intermediate point (however it was reached), is optimal from that point." ⇒ solve the short tail problems first and build longer ones from them.

2.2 Shortest path

  • dist(goal) = 0; dist(X) = minY[cost(X→Y) + dist(Y)], working backwards from the goal.

Example: E 0; B 2+0 = 2; D min{1+0, 1+2} = 1; A 6+2 = 8; C min{3+1, 4+8} = 4; S min{2+4, 1+8} = 6 ⇒ S→C→D→E, cost 6. Greedy S→A (cost 1) is wrong. DP is optimal with no heuristic (unlike A*).

2.3 The DP algorithm

JN(x) = gN(x); Jk(x) = minu∈𝕌 [ gk(x,u) + Jk+1(fk(x,u)) ], k = N−1 … 0

  • Cost J(x0,U) = gN(xN) + Σgk(xk,uk); J* = J0(x0).
  • Forward pass for actions: u*0 = argmin[g0 + J1(f0)], x*1 = f0(x0,u*0), …
  • Jk needed for every state ⇒ discretise; curse of dimensionality ⇒ topics 5 and 6.

2.4 LQR solved by DP

SN = QF; Sk = ATSk+1A + Q − ATSk+1B(R+BTSk+1B)−1BTSk+1A

u*k = Lkxk, Lk = −(R+BTSk+1B)−1BTSk+1A, Jk(x) = xTSkx, J* = x0TS0x0

  • Why: JN−1 = minu[xTQx + uTRu + (Ax+Bu)TSN(Ax+Bu)] is quadratic in u; set d/du = 0, substitute back, repeat by induction.
  • Scalar (a,b,q,r): Sk = q + a²rSk+1/(r + b²Sk+1), Lk = −abSk+1/(r + b²Sk+1).

Example: a=b=q=r=QF=1, N=2: S2=1, S1 = 1 + 1/2 = 1.5, S0 = 1 + 1.5/2.5 = 1.6; L1 = −0.5, L0 = −0.6; J* = 1.6x0². (MPC with N=2 applies L0 = −0.6 every step.)

3 · Stochastic DP & MDPs

3.1 Policies, not sequences

  • xk+1 = fk(xk,uk,wk). Policy π = {μ0,…,μN−1}, uk = μk(xk): reacts to the noise that actually happened ⇒ beats fixed sequences (equal when deterministic).
  • Jπ(x0) = E[gN(xN) + Σgk(xk,μk(xk),wk)]; wk may depend on xk,uk, not on earlier w's.

3.2 The stochastic DP algorithm

JN(x) = gN(x); Jk(x) = minu Ew[ gk(x,u,w) + Jk+1(fk(x,u,w)) ]

  • Minimiser μ*k(x) for every x, k ⇒ optimal policy; store it offline, or store Jk and minimise online.
  • Expectation trick (E w = 0, E w² = σ², w uncorrelated with x, u): E[(a+w)²] = a² + σ². σ² doesn't depend on u ⇒ same best u, higher cost. Vector: E[wTSw] = tr(SΣ).

Example (2024 Q2): xk+1 = x+u+w, gk = gN = βx², N=3. J3 = βx². J2 = βx² + βminu(x+u)² + βσ² ⇒ u = −x, J2 = βx² + βσ². J1 = βx² + 2βσ². J0 = βx² + 3βσ². Pattern Jk = βx² + (N−k)βσ², μk(x) = −x. J0(x0) = 1 ⇔ β = 1/(x0² + 3σ²).

3.3 LQR with noise and packet dropouts

  • Additive noise xk+1 = Ax+Bu+w: same gains Lk (certainty equivalence); cost increases by ΣkE[wkTSk+1wk].
  • Dropouts: Bk = B with prob. Γ, 0 with prob. 1−Γ ⇒ E Bk = ΓB, E[BkTSBk] = ΓBTSB:
    Lk = −(R + ΓBTSk+1B)−1ΓBTSk+1A, Sk = ATSk+1A + Q − ATSk+1ΓB(R+ΓBTSk+1B)−1ΓBTSk+1A. Γ = 1 ⇒ ordinary LQR.

3.4 Markov Decision Processes

  • pij(u) = P(xk+1 = j | xk = i, uk = u), Σjpij = 1. Any MDP ⇔ xk+1 = wk.

Jk(i) = minu [ g(i,u) + Σj pij(u) Jk+1(j) ]

Example (Rover): T, R, B; 0 idle, 1 drive. g(T,0)=−3, g(T,1)=−1, g(R/B,0)=0, g(R/B,1)=2. P(0) = [.75 .25 0; 0 0 1; 0 0 1], P(1) = [.8 .2 0; .9 0 .1; 0 .1 .9]. N=3: J2 = (−3, 0, 0). J1(T) = min{−3+.75(−3), −1+.8(−3)} = −5.25 (idle); J1(R) = min{0, 2+.9(−3)} = −0.7 (drive); J1(B) = 0. J0 = (−7.1125, −2.725, 0). Policy: T idle; R drive at k=0,1, idle at k=2; B idle (driving at the last step isn't worth it).

4 · Infinite-horizon DP

4.1 Discounted cost

  • Jπ(x) = limN→∞ E[Σ αkg(xk,μk(xk),wk)], α ∈ [0,1). α = 0 myopic; α → 1 far-sighted, slower convergence.
  • |g| ≤ M ⇒ |J| ≤ M/(1−α); Σαk = 1/(1−α) (cost 1 per step, α = 0.9 ⇒ 10); Σk≥Kαk = αK/(1−α).
  • Jπ(x0) = E[g(x0,μ(x0),w0)] + αJπ(x1). Optimal policy is stationary. Terminating shortest path: α = 1 allowed.

4.2 Bellman's equation

J*(x) = minu E[ g(x,u,w) + αJ*(f(x,u,w)) ]; J*(i) = minu [ g(i,u) + α Σj pij(u) J*(j) ]

  • J* = fixed point of the Bellman operator TJ = minuE[g + αJ(f)]; the minimiser is μ*. Fixed μ: Jμ(i) = g(i,μ(i)) + αΣjpij(μ(i))Jμ(j).

4.3 Value iteration (VI)

  • Vk+1(i) = minu[g(i,u) + αΣjpij(u)Vk(j)], V0 = 0; matrix Vk+1 = min{G(0)+αP(0)Vk, G(1)+αP(1)Vk} row by row.
  • Vk = optimal k-stage cost; contraction ⇒ Vk → J*, error ≤ αKM/(1−α). The greedy policy often settles before the values (not guaranteed).

4.4 Policy iteration (PI)

  • (1) Evaluate (critic): Jμ = gμ + αPμJμ ⇒ Jμ = (I − αPμ)−1gμ (or iterate).
  • (2) Improve (actor): μnew(i) = argminu[g(i,u) + αΣjpij(u)Jμ(j)]. (3) Policy unchanged ⇒ optimal. Finitely many policies ⇒ finite steps. Rover α=0.96: (0,0,0) → (0,1,0) → (0,1,1).

Example (machine repair): G/D, 0 run, 1 repair; g(G,0)=0, g(G,1)=2, g(D,0)=5, g(D,1)=7; α=0.9; P(0) = [.7 .3; 0 1], P(1) = [.9 .1; .6 .4]. Evaluate (0,0): J(D) = 5 + .9J(D) ⇒ 50; .37J(G) = 13.5 ⇒ 36.49. Improve: G 36.49 vs 36.05 ⇒ repair; D 50 vs 44.70 ⇒ repair. Evaluate (1,1): (26.16, 33.01); improve ⇒ (0,1). Evaluate (0,1): J* = (20.77, 28.46), unchanged ⇒ μ* = (run when good, repair when damaged). VI from 0: V1 = (0, 5), V2 = (1.35, 8.8), V3 = (3.2265, 10.897).

4.5 VI vs PI

  • VI: cheap iteration (one Bellman update), many iterations, values converge only in the limit; gives approx J*, then extract policy.
  • PI: expensive iteration (linear solve), few iterations, exact in finite steps; gives the policy directly (actor–critic).
  • Variants: truncated/optimistic PI, asynchronous updates (visited states only), average cost lim(1/N)EΣg. Rover: α = 0.9 ⇒ μ = (0,1,0); α = 0.96 ⇒ (0,1,1).
  • 2×2 inverse: [a b; c d]−1 = [d −b; −c a]/(ad − bc).

5 · Approximate DP

5.1 Approximation in value space

ũk ∈ argminu [ gk(xk,u) + J~k+1(fk(xk,u)) ] (J~ = approximate cost-to-go)

  • No backward pass: computed forward. J~ = J ⇒ optimal; better J~ ⇒ better policy. J~ from a heuristic, rollout, or a trained model. Loses guaranteed optimality, gains speed.

5.2 Rollout

  • For each candidate action: apply it, then run a simple base (heuristic) policy to the end; J~ = that total. Pick the cheapest, move one step, repeat.
  • Cost improvement: rollout is never worse than the base policy (usually better). Name from Tesauro's backgammon.

Example (TSP): from A: AB100 AC300 AD100 AE75 BC50 BD75 BE125 CD100 CE125 DE50. Nearest neighbour: A-E-D-B-C-A = 550. Rollout: stage 1 B 375, C 550, D 625, E 550 ⇒ B; stage 2 C 375, D 650, E 675 ⇒ C; stage 3 D 375, E 425 ⇒ D ⇒ A-B-C-D-E-A = 375 (optimal here, not always).

5.3 Stochastic problems and certainty-equivalent control

  • Approximate both J~ and the expectation. CEC: replace wk by one typical value wnom (usually E wk) ⇒ deterministic problem minu[g(x,u,wnom) + J~(f(x,u,wnom))]. Exactly optimal for LQG.

Example: x1 = x+u+w, E w = 1, cost u² + x1². CEC (w = 1): min u² + (x+u+1)² ⇒ u = −(x+1)/2. True expected cost only adds Var(w) ⇒ same minimiser.

5.4 Multistep lookahead and truncated rollout

  • ℓ-step lookahead: optimise uk, μk+1…μk+ℓ−1 for E[Σj=kk+ℓ−1gj + J~k+ℓ(xk+ℓ)], apply only the first control (= MPC idea). Larger ℓ compensates a poor J~ but costs more.
  • Truncated rollout: base policy for ℓ−1 steps + terminal J~ (J~ = 0 often fine if ℓ large). Infinite horizon: μ~(x) ∈ argminuE[g + αJ~(f)].

5.5 Parametric approximation

  • J~(x,r) with tunable r (polynomials, Gaussian bases, neural nets). Linear: features φ(x) = [φ1…φm]T (handcrafted, aggregation), J~ = rTφ(x).
  • Train on samples (xs, βs): min ½Σs(J~(xs,r) − βs)² (convex if linear). Least squares: r = (ΣφφT)−1Σβsφ(xs).
  • GD: r ← r − γΣsφ(xs)(rTφ(xs) − βs), γ decreasing; SGD uses one random sample per step. Finite horizon: fit rk backwards per stage; infinite: one r.

Example: φ = [1, x], (x,β) = (0,1), (1,3), (2,7): ΣφφT = [3 3; 3 5], Σβφ = [11; 17], inverse ⅙[5 −3; −3 3] ⇒ r = [0.667; 3], J~ = 0.667 + 3x. One GD step from 0, γ = 0.1: gradient −[11; 17] ⇒ r = [1.1; 1.7].

6 · Reinforcement Learning (tabular, model-free)

  • Learn from experience (apply u, observe cost g and next state x′) with no model f or pij. Alternative: identify a model, then use MPC/DP. Also called neuro-dynamic programming.

6.1 Temporal-difference (TD) prediction

J(xk) ← J(xk) + δk [ g(xk,μ(xk),wk) + αJ(xk+1) − J(xk) ]

  • TD target g + αJ(x′) is an unbiased sample of Jμ(x); the bracket is the TD error; δ = learning rate (Robbins–Monro).

Example: J = 0, α = 0.9, δ = 0.5; A (cost 2) → B (cost 0) → A (cost 2) → B: J(A) = 0.5·2 = 1; J(B) = 0.5(0 + 0.9·1) = 0.45; J(A) = 1 + 0.5(2 + 0.9·0.45 − 1) = 1.7025.

6.2 Q-factors

  • Qμ(x,u) = E[g(x,u,w) + αJμ(f(x,u,w))]: cost of doing u now, then following μ.
  • J*(x) = minuQ*(x,u), μ*(x) = argminuQ*(x,u) (no model needed). Q-Bellman: Q*(x,u) = E[g + α minu′Q*(f(x,u,w),u′)].

6.3 Sarsa (on-policy)

Q(x,u) ← Q(x,u) + δ [ g + αQ(x′,u′) − Q(x,u) ]

  • Uses (x,u,g,x′,u′) = S,A,R,S,A; u′ = action actually taken next. Loop: pick u (ε-greedy); apply, observe g, x′; pick u′; update; x ← x′, u ← u′. Only the visited entry changes; terminal Q = 0 (target = g).

6.4 Exploration: ε-greedy

  • Greedy argmin Q with prob. 1−ε (exploit); random action with prob. ε (explore) ⇒ P(greedy) = 1 − ε + ε/|𝕌|. Decrease ε, e.g. 1/k or max(1/k, 0.01). No exploration ⇒ untried Q stays wrong.

6.5 Q-learning (off-policy)

Q(x,u) ← Q(x,u) + δ [ g + α minu′Q(x′,u′) − Q(x,u) ]

  • Target uses the best next action ⇒ learns Q* while behaving ε-greedily (off-policy). Sarsa learns the values of the policy it follows, exploration included (on-policy) ⇒ more cautious.

Example: Q(s1,a) = 4, Q(s2,a) = 3, Q(s2,b) = 1; observe (s1, a, g=2, s2), exploration picks a; δ = 0.5, α = 0.9. Sarsa: 4 + 0.5(2 + 0.9·3 − 4) = 4.35. Q-learning: 4 + 0.5(2 + 0.9·1 − 4) = 3.45.

6.6 Convergence conditions

  • Every (x,u) visited infinitely often; δk > 0, Σδk = ∞, Σδk² < ∞ (1/k ✓, constant ✗, 1/k² ✗).
  • Sarsa reaches Q* only if ε → 0 (greedy in the limit); constant ε ⇒ Q of the ε-greedy policy. Rover runs: δ = 0.1, εk = max(1/k, 0.01), 500 episodes × 1000 steps.

6.7 Bigger problems and caveats

  • Use Q(x,u;r) (e.g. a neural net), minimise E[(g + α minuQ(x′,u;r) − Q(x,u;r))²] by GD (deep RL, DQN). Learning convergence ≠ closed-loop stability; use known structure.
  • Rewards instead of costs: best action = max Q (or cost = −reward); Sarsa update unchanged; Q-learning uses max.

Example (2024 Q3): (Sarsa δ = 0.1, α = 0.5; ep1 1A, 2A, 4B, 4B; ep2 1B, 3A, 2A, 4B): Q(2,A) = 0.1·100 = 10; Q(4,B) = 0.1(100 + 0) = 10; Q(3,A) = 0.1(0 + 0.5·10) = 0.5; Q(2,A) = 10 + 0.1(100 + 0.5·10 − 10) = 19.5; rest 0. Tie at 1 ⇒ r + α·max Q(next): A 9.75 > B 0.25 ⇒ 1→A→2→A→4.
